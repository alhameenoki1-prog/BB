Sign in with Google and Microsoft

These buttons connect a mailbox with the account the browser is already signed in to: one click, no password typed into this site, and it keeps working after the password changes. Google and Microsoft allow that only through an app the site owner registers once. Do it here once (about five minutes each) and the buttons work for everyone on this site.

{{ icon('mail', 16) }} Google (Gmail and Google Workspace) {{ 'on' if st.google_on else 'off' }}

  1. Open console.cloud.google.com and create a project (any name, e.g. "BB mail").
  2. Enable the Gmail API for it.
  3. Google Auth Platform → Get started: app name, your email; audience External. Under Data access add the scope https://www.googleapis.com/auth/gmail.modify (read, send and label mail). Under Audience, while the app is in testing, add every Gmail address that will connect as a test user (Google signs testing apps out after about seven days; publish the app to stop that).
  4. Clients → Create client → Web application. Under Authorized redirect URIs add both:
    {{ google_uris[0] }}
    {{ google_uris[1] }}
  5. Create, then paste the Client ID and Client secret here and save.

{{ icon('mail', 16) }} Microsoft (Outlook, Hotmail, Microsoft 365) {{ 'on' if st.microsoft_on else 'off' }}

  1. Open entra.microsoft.com → App registrations → New registration (any name).
  2. Supported account types: Accounts in any organizational directory and personal Microsoft accounts.
  3. Redirect URI: platform Web, then add both (the second under Authentication → Add URI):
    {{ ms_uris[0] }}
    {{ ms_uris[1] }}
  4. API permissions → Add → Microsoft Graph → Delegated: Mail.ReadWrite, Mail.Send, User.Read, offline_access.
  5. Certificates & secrets → New client secret; copy its Value. Copy the Application (client) ID from Overview. Paste both here.

Set in the server's own settings (bb.env or the environment); change it there.
