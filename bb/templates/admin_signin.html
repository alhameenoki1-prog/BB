Sign in with Google and Microsoft

These buttons connect a mailbox with the account the browser is already signed in to: one click, no password typed into this site, and it keeps working after the password changes. Google and Microsoft allow that only through an app the site owner registers once. Microsoft is one button here; Google is a few screens of its own (about five minutes). After that the buttons work for everyone on this site.

Google lets no site make this for you, so it is a few screens in Google Cloud, signed in as you already are. Each link opens the exact screen; at the end you drop the file Google gives you here, and nothing is copied by hand.

  1. Switch on the Gmail API: pick a project or create one (any name, e.g. "BB mail"), then Next and Enable.
  2. Google Auth Platform → Get started: an app name, your email, audience External, your email again, agree, Create.
  3. Data access → Add or remove scopes → paste https://www.googleapis.com/auth/gmail.modify → Update, Save. Then Audience: add every Gmail address that will connect as a test user (or Publish app; testing apps are signed out after about seven days).
  4. Create client: type Web application; under Authorized redirect URIs add both, then Create:

Let the site do steps 1 to 5. Sign in on Microsoft's own page with the account your browser already uses, and the site registers the app in your directory with both sign-in addresses and the mail permissions, makes its secret and switches the button on. Nothing but a one-time token for this reaches the site.

Needs a work or school Microsoft account that may register apps (the owner of a Microsoft 365 or Entra directory can; a free Microsoft 365 developer account has one). Microsoft asks you once to agree that the setup may manage app registrations.
